# 隐私与本机数据

MOS 是连接你指定 Hermes 网关的原生客户端。客户端 Mac、Hermes 主机和模型／工具服务是不同的数据边界。

## 登录与连接

- 网关地址、用户名、主题和部分界面偏好使用本机 UserDefaults。
- 密码在登录时传给指定网关，不持久保存。
- access／refresh token 使用 macOS Security Framework 存入钥匙串，服务标识沿用 `local.hermes.remote`。
- 登录使用原生 PKCE／state 校验；连接使用网关签发的 WebSocket 票据。
- HTTPS 提供传输加密；HTTP 不提供。使用私有网络本身不等同于应用层 HTTPS。

## 显示缓存和草稿

为在短暂断网或重新启动时尽快恢复界面，近期聊天正文和草稿存放在：

```text
~/Library/Application Support/local.hermes.remote/Conversations/
```

旧版可能存在 `~/Library/Caches/local.hermes.remote/Conversations/`，代码包含迁移与退出清理路径。

缓存按网关与账号隔离，限制最多 16 个 Bot、每个 240 条消息、30 天、每文件 12 MB；超限时裁剪较旧内容。它只是显示副本，不能代替远端会话身份，也不自动重发结果不明的消息。

**缓存不加密，包含消息正文和草稿。** 文件权限限制为当前用户访问；这不构成应用层加密。缓存不保存登录令牌、待处理审批、附件本地路径或图片字节。

## 附件、头像与配置

附件在本机暂存以支持发送前预览，点击发送才上传至当前网关／Bot。下载文件保存在你选择的位置。不要把附件当作仅保存在本机的内容。

头像与外观偏好主要保存在本机。头像选择按网关、账号与 profile 隔离，不修改远端角色和长期记忆。

编辑模型、SOUL、工具、Skills、MCP 或消息平台并保存，会向目标 Hermes profile 写入配置；其中平台或服务凭据由远端按其配置方式保存。当前聊天模型切换同样是对远端会话的操作。

## 退出登录

退出登录会阻止自动恢复，清除当前账号显示缓存，并异步请求删除当前网关的钥匙串凭据。外观和头像偏好可以保留。保存／读取钥匙串失败时，以客户端错误提示为准。

如果另一账号使用同一网关，钥匙串记录以网关键管理；不要把退出登录视为服务端全账号令牌吊销。远端登录、历史、备份和集成的数据保留由 Hermes 及所用服务决定。

## 第三方和反馈

应用请求面向你指定的网关。Hermes 使用的模型、工具、消息平台或 MCP 服务可能把任务数据发送给你配置的第三方，按它们的配置和政策处理。随包字体在进程内注册，无需联网下载。

公开反馈请仅使用脱敏截图与最小复现，不上传完整聊天缓存、钥匙串、令牌、账号或私人网关地址。安全问题见 [SECURITY.md](../SECURITY.md)。
